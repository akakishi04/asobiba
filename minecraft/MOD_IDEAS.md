# AsobibaTweaks backlog

The rule for this mod is: small features, individually switchable, no feature is allowed to become a hard dependency for another feature.

## Strong candidates

### Item personality
Growing items gain a trait at milestones. Examples: stubborn pickaxe (slower but durable), bloodthirsty sword (kill streak bonus), careful shovel (rare durability refund).

### Sleep roulette
Sleeping rolls one temporary rule for the next Minecraft day: low gravity, fast crops, fragile tools, angry animals, stronger knockback, etc.

### Cursed chunks
Rare chunks receive a local rule such as reversed knockback, darkness, rapid plant growth or unusual mob behavior. Keep rules deterministic from world seed + chunk position.

### Micro quests
Generate tiny contextual goals: mine 16 blocks without taking damage, return home before night, kill one mob using an unusual item. Rewards should be small and weird rather than progression-breaking.

### Death echo
On death, leave an optional echo challenge at the death point. Recovering it can restore a portion of lost XP or grant a temporary effect.

### Mob grudge
A mob that survives an encounter with the player can become named/marked and slightly stronger if encountered again.

### Resource fatigue
Repeatedly mining the same block type in a short interval can trigger harmless oddities: sounds, particles, temporary tool quirks or a tiny chance for the ore to relocate.

## Avoid for now

- Large tech trees.
- New dimensions.
- Massive content packs.
- Anything that makes AsobibaTweaks mandatory for world loading.

Those belong in their own mods.
