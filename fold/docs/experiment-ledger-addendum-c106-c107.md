Experiment: `C106-v5e-unseen-eligibility-mask-generalization`

Purpose: falsify the hypothesis that C104/C105 succeeded only because all 16 eligibility masks were seen during training.

Prospective split:

```text

OOD masks:   Hamming weight >= 3  (5 masks)

validation base: 3 only
fresh seeds: 20261231,20261232,20261233
```

Accepted result across all fresh seeds:

- unseen OOD masks were never present in training;
- anchor action accuracy `1.0`;
- anchor minimum six-class recall `1.0`;
- OOD action accuracy `1.0`;
- OOD minimum-burden selection `1.0`;
- OOD ineligible mechanism predictions `0`;
- OOD action flips `0`;
- OOD hidden-counterfactual action invariance `1.0`;
- C37 and fixture preserved;

Interpretation:

The simple explanation "the router memorized all 16 eligibility masks" is materially weakened. The learned mechanism policy generalized from low-Hamming-weight masks to five unseen high-Hamming-weight compositions while also generalizing to unseen base=3.

This does not yet rule out a shared train/eval generator bug because C106 still uses the same benchmark implementation family for training semantics and evaluation semantics.

## C107 — ACTIVE falsification

Experiment: `C107-v5e-independent-evaluator-falsification`

Question:

> Does the C106 training path still pass when evaluation rows and expected actions are generated by an independently written evaluator that imports none of the C97-C106 oracle/generator modules?

Design:

- training remains the accepted C106 canonical training family;
- fresh seeds: `20261301,20261302,20261303`;
- evaluation uses `gate_e_c107_independent_eval_fixture.py`;
- independent fixture reconstructs visible state and action truth with separate code;
- independent fixture uses all 16 masks on unseen base=3;
- evaluation row order intentionally differs from the canonical generator;
- target/hidden truth is not added to router inputs;
- independent labels are compared against canonical labels as a separate semantic-agreement diagnostic.

Prospective C107 gate:


A valid negative result completes C107. Do not loosen these conditions retrospectively.
